# Senkron - Akıllı Otopark Yönetim Sistemi

Akıllı Otopark Yönetim Sistemi, şehirlerde yaşanan park yeri bulma problemini azaltmayı amaçlayan web tabanlı bir yazılım projesidir.

## Proje Yapısı
- **`index.html`**: Kullanıcı arayüzü ve canlı otopark durumu ana sayfası.
- **`pages/`**: Projenin diğer arayüzleri (Giriş, Kayıt, Admin Paneli).
- **`assets/`**: Projede kullanılan görseller ve logolar.
- **`css/` & `js/`**: Özel stil ve etkileşim dosyaları.
- **`backend/`**: Sistemin sunucu (Node.js vb.) kodlarının yer alacağı klasör (İlerleyen sprintlerde eklenecektir).
